# Mohamed S. Gaballah — Multi-page academic website

## Pages
- `index.html` — About / homepage
- `research.html` — Research
- `publications.html` — Publications
- `teaching.html` — Teaching
- `industry.html` — Industry, including Leadership & Professional Service
- `awards.html` — Awards, honors, international fellowships, and recognition
- `contact.html` — Contact

All pages share the same navigation, stylesheet, footer, and analytics from the original website.

## Install
Copy these files into the **root** of your existing GitHub Pages repository, replacing the old files and adding the new HTML pages (including `awards.html`). **Keep your existing `assets` folder unchanged**; the pages continue to reference the existing image and CV paths under `assets/`.

Then commit and push the changes to `main`. GitHub Pages is already configured to publish from `main` / root.
